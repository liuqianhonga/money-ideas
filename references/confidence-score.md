# 信心指数（Confidence Score）评分体系

每个项目除了可行性评分（feasibility 1-5），新增**信心指数**（confidence 0-100），
由三个子维度合成，帮助快速判断「这个项目我该不该投入」。

## 三个子维度（frontmatter 新增字段，各 1-5 分）

| 字段 | 含义 | 1 分（好做） | 5 分（难做） |
|------|------|-------------|-------------|
| `effortScore` | 实施难度 | 1-2 周可启动，纯内容/工具 | 需要 6 个月+ 研发/复杂系统 |
| `barrierScore` | 门槛（资金/资质/资源） | 零成本，个人即可 | 需要大额资金/资质/团队/行业资源 |
| `monetizationEase` | 变现难易 | 接单即收/卖货即到账 | 6-12 个月冷启动，销售周期长 |

> 注意方向：`monetizationEase` 分数越高 = 变现越容易；另外两个分数越高 = 越难。
> 合成公式里会自动反转难度类维度，保证「信心指数越高 = 越值得做」。

## 合成公式

```
confidence = round( 100 × (
    0.4 × (monetizationEase / 5) +
    0.3 × (1 - (effortScore - 1) / 4) +
    0.3 × (1 - (barrierScore - 1) / 4)
))
```

- 变现难易权重最高（40%）：赚不赚钱是核心
- 实施难度 + 门槛各 30%
- 输出 0-100 整数，首页/详情页展示

## 评级参考

| 区间 | 建议 |
|------|------|
| 80-100 | 🔥 极佳：低门槛、快变现，优先考虑 |
| 60-79 | ✅ 良好：可行，需要一定投入 |
| 40-59 | ⚠️ 一般：有潜力但门槛/周期长 |
| 0-39 | ❌ 谨慎：难度大或变现慢 |

## 示例

```yaml
effortScore: 2        # 2 周可启动
barrierScore: 2       # 个人可做，少量资金
monetizationEase: 4   # 订阅制，2-4 个月见收入
# confidence = round(100 × (0.4×0.8 + 0.3×0.75 + 0.3×0.75)) = round(100 × 0.77) = 77
```

## 与 feasibility 的区别

- `feasibility`（可行性 1-5）：偏「这个方向能不能成」——市场验证、需求真实性
- `confidence`（信心指数 0-100）：偏「我该不该投入」——难度/门槛/变现综合
