# Experiential：开源「智能 LLM 路由网关」——OpenRouter 的开源替代 + 按成本/质量最优路由，用你们的流量换个更好的模型

> **Show HN：[experientiallabs/experiential](https://github.com/experientiallabs/experiential)（HN 讨论 `49471407`）**——作者说得很直接：**简单的路由器不配收 10% 的 token 加价。** 他们做了一个开源模型网关，统一纳管自托管、前沿、开源模型，并用标准化 OTel 追踪 + 文本世界模型模拟 + LLM judge 为**每个请求**自动选「成本/质量最优」的模型。因为大模型持续大幅降价，这让「按最优性价比路由」从加分项变成企业**降本刚需**。

## 是什么

Experiential 是一个开源（Rust 原生、面向并发）的 **LLM 模型网关**，核心能力：

- **统一入口**：一个地方管理你自己的自托管模型 + 前沿模型 + 开源模型，实现各家 provider 的流式格式、工具调用、参数、限流、错误行为的差异
- **智能路由**：不靠单一模型，而是通过对标准化 OTel 追踪挖出**真实任务**，用文本世界模型模拟多个模型在这些任务上的推断，LLM judge 打分，再在 prompt 的 embedding 上拟合一个近邻分类器，对每个请求选最优模型——通常能得到比单一模型更好的**成本/质量 pareto 曲线**
- **不加价**：宣称 0 markup，还有 1000+ 模型每天由 codex agent 开 PR 刷新
- **可自托管**：开源，能部署在自己基础设施；也可用托管版（BYOK 请求加 <1ms、自带 key 加 <2ms）
- **增值**：用你的流量（可选）训练一个专属更好的模型

## 商业模式

**开源网关 + 托管版 + 增值服务**。网关本身开源、不加价，赚钱靠：① 托管的「路由 + 模型市场」服务（企业不想自运维）；② 企业级「LLM 成本/质量优化」的咨询或定制模型训练；③ 作为一家公司的差异化——「我们的路由比单个模型更省钱、质量更高」。

## 变现方法

- **托管网关按用量 / 订阅**：帮团队省掉自运维，0 markup + 订阅费（或按优化省下的钱分成）
- **LLM 路由与成本优化咨询**：大模型降价后「我的流量该走哪个模型」成了真问题，卖服务/审计
- **为特定团队训练专属模型**：用对方流量训练定向优化的模型，高价值企业单
- **企业私有化部署授权**：数据敏感的团队要自托管网关 + 支持，收 license

## 门槛

**高。** 不是套个代理那么简单：既要实现 1000+ 模型、各 provider 的配置差异化与高并发网关，又要做「路由引擎 + 世界模型模拟 + 模型评测」这套 ML 纵深。个人/小团队能做，但对工程能力与 LLM 评测理解要求高，且要**证明路由真的比单模型更好**才有人买单。

## 所需技能

- **LLM / 推理服务工程**：多 provider 接入、流式、限流、错误处理
- **模型评测与 LLM-as-judge**：判断「哪个模型对这个任务更好」的路由核心
- **Rust / 高并发网关开发**：低延迟、高并发（作者称 BYOK 请求加 <1ms）
- **可观测性（OTel 追踪）**：用真实任务信号驱动路由
- **LLM 应用架构**：把网关嵌入企业实际调用链

## 变现周期

**4-8 个月。** 网关与企业**推理成本**深度绑定，信任是关键——必须先拿出「路由后成本下降 X%、质量不降」的可量化结果，再谈订阅/服务。从开源攒用户到企业付费需 4-8 个月。

## 投入成本

**中。** 时间为主；模型评测、备份自托管推理、模拟训练有持续算力成本；托管版需按流量计费的推理/带宽支出。

## 可行性：3/5

## 实操步骤

1. 先用开源版把自己的多模型调用统一到一个网关，跑通「流式/工具调用/限流」基础层
2. 用 OTel 追踪收集真实任务样本，搭路由评估闭环（多模型候选 + LLM judge + 成本记录）
3. 在自己项目里验证「成本降多少、质量掉没掉」，固化可量化案例
4. 开源并在 HN / AI 社区发布，强调「不加价的 OpenRouter 替代 + 智能路由」
5. 找 1-2 个中大型团队试跑，给出成本/质量对比报告，拿一个付费试点
6. 视反馈扩展：企业私有化部署、专属模型训练、成本优化咨询

## 风险与坑

- **模型更新太快**：1000+ 模型每天在变、各家降价，路由评测要跟上，否则「最优」随时失效——维护成本高
- **「智能路由」的信任门槛高**：团队凭啥信你选的模型？**必须给可量化的成本/质量对比**，别卖玄学
- **竞争激烈**：OpenRouter、各云平台内置路由都在做，差异化要靠「开源、不加价、用真实任务学」的立场与深度
- **算力开销**：自托管、模拟、评测都有成本；托管版定价要覆盖意图的按量波动

## 启发

**AI 推理在持续大幅降价，「模型只会更多更便宜」意味着『帮企业选对模型、把钱省下来』成为一个越来越值钱的服务。** 这个项目的核心洞察是把「路由」从一个静态代理升级为「用真实任务数据 + 评测学出最优性价比」的智能层，并且**拒绝对 token 加价**——把变现放在「优化省下的钱 / 专属模型 / 托管」上。对个人/小团队，直接做全套 Rust + 世界模型门槛偏高，更现实的切入是：**先做「给单个团队/单类任务做模型路由评测 + 成本优化」的顾问或轻网关**，拿到案例再谈产品化。记住转述里那句判断——「简单路由不配收 10% 加价」，差异化要在「真的更优」上，不在「转手加价」上。
