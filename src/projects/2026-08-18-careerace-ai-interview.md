## 是什么

[CareerAce](https://careerace.app/)（独立开发者产品，2026-08-16 收录进 chinese-independent-developer 金矿）是一个 **AI 模拟视频面试与求职辅导工具**：上传简历后，AI 根据你的简历和目标岗位发起多轮面试提问，并**根据你的实时回答继续追问**，面试结束后生成评估报告，指出表现和提升方向。支持 Web、iOS、Android。

**为什么这个机会成立**：AI 面试辅导是 2026 年求职赛道的大热方向——面试本身高度标准化（行为问题、岗位技能、临场反应），非常适合 LLM 模拟；求职者「面试失败的成本」很高，付费意愿强；国内外竞争密度仍在早期（相比 AI 写作/画图）。

## 商业模式

**Freemium SaaS**：
- 免费版：有限次模拟面试（体验用）
- 付费版：无限模拟 + 评估报告 + 简历优化 + 面试复盘笔记
- 企业端（远期）：人才测评工具的 API 输出

## 变现方法

1. **月订阅**：$9-29/月（核心，海外定价）；国内版本 ¥29-69/月
2. **单次付费**：临时抱佛脚的付费用户，一单 $4.9-9.9
3. **报告增值**：深度评估报告单独收费
4. **简历/求职信优化**：相邻产品线交叉销售
5. **广告联盟/课程**（后期）：面试题库、面经内容变现

## 门槛

中等：不需要牌照（非招聘中介，是练习工具），但要搞定三块技术——
- 语音对话（Realtime API 或 STT+LLM+TTS 组合）
- 简历解析（PDF 文本提取）
- 追问逻辑（LLM prompt 编排）与评估报告生成（评分卡模板）
以及移动端（可先用 Web 版再包壳）。

## 所需技能

LLM 应用开发（API 调用 + prompt 编排）、语音 API 集成、基础前端；求职/HR 领域知识是差异化关键（问题库、评分维度）

## 变现周期

2-3 个月：MVP 2-3 周 → 内测 1 个月 → 上架（Web 先行）→ 前 3-5 单付费（1-2 个月）

## 投入成本

- 资金：API 费用为主（模拟一次面试约 $0.1-1），月成本几百元级别
- 时间：MVP 2-3 周全职 / 1-2 个月业余

## 可行性：4/5

需求高度验证：求职是刚需，面试辅导付费意愿极强；技术栈全部现成（语音 API 成熟）；竞品（CareerAce、各大厂 AI 面试）也证明了这个品类能跑通。风险主要在获客（求职类产品靠内容 SEO/小红书/社群冷启动）。

## 实操步骤

1. 定位：选细分人群（应届生/程序员/外企英语面试/教师编面试），先做透一个
2. MVP：简历上传（PDF 解析）→ AI 面试官多轮提问（可先用文字+音转的文字模式跑通，再加语音）→ 报告生成
3. 题库建设：收集目标岗位真实面试题，做评分卡（流利度/结构/内容/匹配度）
4. 上 Web 版 + Product Hunt/小红书/即刻发帖，收集 20-50 个真实用户体验
5. 定价测试：免费 3 次 → 订阅/单次
6. 迭代：加语音视频模式、行业题库、企业端

## 风险与坑

- **大厂入场**：招聘平台自带 AI 面试辅导会挤压独立产品空间（差异化靠细分人群+体验）
- **仿真度不足**：AI 面试官太机械会被骂「玩具」（追问逻辑要下功夫）
- **隐私合规**：简历属敏感数据，需加密存储、可删除
- **获客难**：工具型产品无流量入口，SEO/SEM 竞争激烈
