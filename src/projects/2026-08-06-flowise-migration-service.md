## 项目是什么

**这是信号型商机**：Flowise（低代码 LLM 工作流构建工具）官方于 2026-08-05 宣布 sunset（关停）。官方公告 https://flowiseai.com/sunset 显示 2026-07-29 开始逐步停止运营，建议用户 fork 代码自谋出路。

Flowise 曾是一个月活数万的低代码 AI 应用构建平台，大量个人开发者、小团队用它搭聊天机器人、RAG 工作流、Agent。关停意味着：
- **存量用户必须迁移**（数据、工作流、流程）
- **没人愿意自己维护** → 外包迁移/托管需求爆发

## 怎么赚钱

1. **迁移服务**（最快）：帮用户把 Flowise 工作流迁到 n8n（免费开源）或 Dify（国内友好），按项目收 ¥2000-20000
2. **自托管代运维**：帮用户 fork + Docker 部署 Flowise 到自己服务器，收部署费 + 年维护费
3. **导出工具**：做一个「Flowise → n8n/Dify 转换器」，卖 License 或 SaaS
4. **替代方案咨询**：评估企业现有 Flowise 资产，出迁移方案文档（咨询费）

## 为什么能赚钱

- **需求确定**：关停公告已发，用户**必须**行动，不是「可能有机会」而是「正在发生」
- **时间窗口**：公告到完全关停有几周-几个月，迁移需求集中爆发期
- **竞品承接**：n8n/Dify 都在争抢 Flowise 用户，会配合提供迁移文档/优惠——借势
- **技术门槛低**：Flowise/n8n 都是可视化拖拽，熟悉一个就懂 80%；个人可承接
- **国内落地**：Dify 在国内有大量用户，帮国内团队迁移 Dify 是现成需求

## 实操步骤（从零开始）

1. 立即注册账号试用 Flowise（趁还活着），导出几个典型工作流做演示素材
2. 学习 n8n 和 Dify 的 Flowise 迁移（官方有 migration guide）
3. 写 1-2 篇《Flowise 关停了，迁移到 X 的完整指南》发掘流量（SEO 黄金期）
4. 在 Flowise 社区/Discord/Reddit 发迁移服务帖
5. 定价：基础迁移 ¥2000-5000/项目，企业级含维护 ¥1-5 万/年
6. 交付：流程图对比 + 迁移 + 测试 + 交接文档

## 风险与坑

- 时间窗有限：Flowise 完全关停后流量自然衰减，要趁热打铁
- 竞品官方免费迁移工具可能推出，压缩付费空间（但多数用户仍需人工服务）
- 迁移复杂度差异大：简单聊天机器人 2 小时，复杂 RAG 工作流要几天，报价要先评估
- 不要接「保证完全等价」的承诺——不同平台能力边界不同
