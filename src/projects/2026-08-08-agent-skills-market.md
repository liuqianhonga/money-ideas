# Agent Skills 技能包生意（AI 时代的插件经济）

## 是什么

Agent Skills 是给 AI 编码/办公 Agent（Claude Code、Codex、Gemini CLI、Cursor 等）安装的「技能包」——把某个领域的工作流、质量标准、最佳实践封装成可复用的 SKILL 文件，让 AI 自动按该流程执行任务。

2026-08-08 这天，GitHub Trending 上 **4 个 Agent Skills 类 repo 同时登榜**：
- `obra/superpowers`：268,733⭐，Agent 技能框架 + 软件开发方法论
- `mattpocock/skills`：208,791⭐，TypeScript 专家技能集
- `addyosmani/agent-skills`：83,890⭐，生产级工程技能（Chrome 团队前技术负责人出品）
- `google/skills`：16,243⭐，Google 官方技能库

连 Google 都官方下场了，说明这是**确定性趋势**而非昙花一现。Superpowers 项目本身已经开放企业商业服务（sales@primeradiant.com），验证了付费意愿。

## 怎么赚钱

**三个变现路径，按难度递增：**

1. **垂直领域技能包直接售卖**（最快）——把「会计报税」「跨境电商选品」「法律合同审查」「SEO 内容生产」等工作流做成技能包，在 Gumroad / Lemon Squeezy / 自建站卖买断或订阅。已有大量开发者买「工程技能包」，但**非技术行业（财务/法律/医疗/教育）的技能包极度稀缺**，这是机会。
2. **企业定制打包**——帮企业把内部工作流封装成技能包（如客服 SOP、审核流程、数据分析流程），按项目收 5k-50k。Superpowers 已经证明企业愿意付钱。
3. **技能包导航/聚合站**——收录全网技能包做筛选导航（类似 WordPress 插件目录），靠广告、置顶、联盟佣金变现。需求已起来但目录站还很少。

## 为什么能赚钱

- **需求真实且爆发**：Claude Code/Codex 等 Agent 装机量暴涨，用户发现「裸 Agent 不够好用，装技能包才好用」——这是生态位空缺
- **Google 入场是风向标**：大厂官方做技能库 = 市场教育免费帮你做
- **非技术垂直领域是蓝海**：通用工程技能包已拥挤，但行业专家技能包（医生/律师/财务/外贸）几乎没有供给
- **数字产品边际成本为零**：一份技能包可以无限卖，符合数字产品经济模型

## 实操步骤

1. **选垂直领域**：挑一个你懂行的行业（你做过会计/外贸/运营/律师助理都算），别做通用编程技能（太卷）
2. **拆解工作流**：把该领域 3-5 个高频任务写成步骤化 SOP（如「跨境电商选品」= 关键词挖掘→竞争分析→利润测算→合规检查）
3. **封装成 SKILL 格式**：参考 superpowers/agent-skills 的 SKILL.md 结构（name、description、instructions、steps），GitHub 上有现成模板
4. **自测打磨**：用 Claude Code/Codex 安装自己的技能包跑真实任务，迭代到「输出质量明显优于裸 Agent」
5. **上架销售**：Gumroad/Lemon Squeezy 卖 $9-49 买断，或 Patreon/自建订阅 $19-99/月（持续更新）
6. **冷启动**：在 r/ClaudeAI、V2EX、X（推特）发「我是怎么把 X 行业工作流封装成技能包的」实测帖，附对比演示

## 风险与坑

- **格式还在演进**：Claude Skills / Agent Skills 格式未完全统一，可能需适配多平台
- **头部免费竞争**：通用技能包免费+开源（superpowers 等），必须走垂直/行业差异化
- **AI 能力变化快**：模型升级可能让部分技能包价值缩水，需持续迭代
- **别碰搬运抄袭**：直接抄开源技能包改个名卖会翻车，要做真正的行业知识封装
