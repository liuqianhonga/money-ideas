## 是什么

[Beautiful Public Data](https://www.beautifulpublicdata.com/boat-names/) 是记者 Jon Keegan 的公共数据挖掘站。最新作品：从 NOAA Marine Cadastre 公开船只 AIS 数据中采样 5 万个**船名**（SEA SLUT II、BILBOAT BAGGINS 这类梗名），做成可搜索/按分类浏览/随机展示的互动站，还配了长篇图文解读（船主职业、影视梗、文学梗分析）。

HN 32 分、15 条评论，这个站本身就是「公共数据变现金矿」的活教材——过去做过车牌号、核武器、月球岩石、处方药等一堆数据可视化内容。

## 商业模式

**内容免费引流 + 多路变现**：

1. **数据包下载**：5 万船名数据集放 GitHub 免费下载，建立信任
2. **周边电商**：把数据可视化做成 T 恤、裱框挂画卖（shop.beautifulpublicdata.com），数据本身免费但"艺术化呈现"收费
3. **Newsletter 订阅**：免费订阅积累私域，后期可接广告/付费版
4. **Buy me a coffee**：单次打赏

核心逻辑：**公共数据免费 → 内容/产品增值收费**。

## 变现方法

- 数据可视化周边（挂画、T 恤）：数据可视化的"艺术化"是有付费意愿的（数据新闻周边是成熟品类）
- Newsletter 订阅制：优质数据故事打包
- 后续可扩展：企业数据故事定制、数据新闻代笔

## 门槛

- **技术门槛**：低-中。Python 数据处理 + 可视化（这个项目还用了 Claude Code 辅助分类）
- **资金门槛**：极低，百元级（域名+部署）
- **资质门槛**：无。公共数据公开，注意遵守数据源使用条款

- 内容叙事能力（把数据讲成故事）
- 基础 SEO/社交媒体分发

## 变现周期

1-3 个月：内容发出来就有打赏/周边首单，Newsletter 需要时间积累。

## 投入成本

- 资金：百元级
- 时间：2-4 周/篇数据故事

## 可行性：4/5

模式成熟可复制：**中国也有大量开放数据**（统计局、气象局、公共资源交易、招聘网站）没被做成产品。找"有情感共鸣的数据"（车牌号、网名、店铺名、宠物名）最容易爆。

## 实操步骤

1. 选一个有趣的中国开放数据集（如：全国车牌号、外卖店铺名、公园名字、宠物登记数据）
2. 用 Python 清洗 + 挖掘梗/有趣规律
3. 做可视化互动页 + 写长文解读（模仿 beautifulpublicdata 的叙事风格）
4. 发 HN/V2EX/小红书/公众号，标题走"5 万个XX名"猎奇路线
5. 同步做周边（挂画/海报）上架微店/淘宝，数据包免费下载引流
6. 积累 Newsletter/公众号私域，接广告或做付费专栏

## 风险与坑

- ⚠️ 数据合规：公开数据使用注意原始条款，涉及个人信息需脱敏（船名是 AIS 公开广播数据，合规性较好）
- ⚠️ 猎奇流量不稳定：需要持续产出，建立系列感
- ⚠️ 周边电商物流成本：可先做定制印刷（按需打印）避免囤货
- ⚠️ 国内开放数据质量参差，清洗成本可能高于预期
