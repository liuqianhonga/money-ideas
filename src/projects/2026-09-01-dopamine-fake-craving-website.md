# 『假装点外卖』多巴胺网站：消费降级下的情绪价值生意，用 AI 三天搭一个

> **虎嗅 2026-08-31 报道**：『假装点外卖』虚拟消费网站正全球爆红——韩国 App「음식만안와요」（只有饭没来）每周被下单几万次，创始人当初是用 GPT 辅助搭起来的；国内冒出「逃宝」（假装淘宝下单）、「丑团外卖」（假装点外卖）、「在线赛博抽烟室」，抖音甚至推出「馋猫外卖」。这些网站的共性是：**钱不会真花，但快乐是真的。**

这是一个被刷屏验证过的、几乎零门槛的个人副业方向，特别适合这个「消费降级但需要情绪出口」的时代。

## 是什么

『多巴胺网站』是一类**虚拟消费网页**：界面一比一复刻真实的点外卖 / 逛淘宝 / 点菜 / 抽烟 / 打游戏抽卡，但一切都是假的——外卖不会送上门、购物车不会真扣钱、香烟是赛博的。用户图的不是「买到」，而是**下单那一刻的多巴胺分泌**：

- **假装点外卖**（韩 음식만안와요、国内「丑团外卖」）：完整复刻凑满减、抢神券、下单、外卖员逼近的配送动画，下单后还告诉你这一顿「省了多少卡路里、多少钱」。
- **假装购物**（FakeHaul、逃宝）：每件商品都挂 -xx% 折扣，让你无痛清空购物车。
- **赛博多巴胺吸烟室**：双击手机屏幕弹烟灰，还能发匿名碎碎念。
- **假装打药 / 假装炒股 / 假抽泡泡玛特**：民间智慧已经延伸到各种「想爽但不敢真花钱」的场景。

**本质**：在经济压力大、奖励机制丰富的时代，用户需要「花小钱办大事」的爽感，虚拟消费提供了无痛的多巴胺。心理学上这叫「奖励预测」——快到手的兴奋，比真正拥有更强烈。

## 商业模式

- **基础：免费获客**。多巴胺网站靠猎奇 + 情绪共鸣传播（虎嗅报道后自带流量），不设门槛。
- **变现①：广告**。情绪价值流量就是广告位，类比工具站/小游戏。
- **变现②：自愿打赏**。韩国 App 用户「人均消费大几百」，纯为爽感和满足感自愿付费——这是这个赛道最奇妙的地方，用户主动给钱。
- **变现③：会员/皮肤/定制玩法**。付费解锁更多「都市爽点」、更多菜系流派、更沉浸的视觉主题。
- **变现④：品牌合作**。饮料/零食/运动品牌愿意为「劝你忍住不买」这种反向种草做植入。

## 变现方法

1. **单站跑通 → 批量复制**：做一个爆款玩法（假点外卖）拿到流量和数据，再复制到假购物、赛博抽烟、假开箱等 3-5 个变体，形成站群矩阵互相导流。
2. **广告 + 打赏双通道**：接广告联盟 + 页面放「打赏」入口（支持者光顾后自愿投币）。
3. **差异化玩法沉淀**：把「假装点什么」做成社区，让用户自己发明新玩法并投票，你把它做出来。
4. **AI 加成**：用 LLM 生成菜品/文案/个性化推荐（韩国鼻祖就是 GPT 搭的），做出「连选择困难症都关怀」的完整体验。

## 门槛

- **技术**：极低。纯静态页 + 基础交互即可，静态站免费部署；想加 AI 推荐（FoodNeverComes 的招牌功能）就接一个 LLM API，前端工程知识即可。
- **资金**：趋近于零。Vercel/Netlify/Cloudflare Pages 免费托管，域名几十块/年；加 LLM 功能每月几十元 API 费。
- **资质**：无。

## 所需技能

- 前端（HTML/CSS/JS，或 Next.js/React）能搞定 90% 的站点。
- 文案 / 产品创意：这是核心壁垒——能不能提炼出让人「爽到」的交互细节。
- 基础 LLM API 调用（生成菜品名、推荐、个性化文案）。
- 社交传播：懂得在抖音/小红书/微博制造议题（「假装点外卖」本身就是个话题）。

## 变现周期

- **1-3 个月**：一个爆款玩法做好 + 传播起来，广告和打赏开始回流。单站成本趋近于零，跑通一个模式就能复制。

## 投入成本

- **资金**：几乎为零，免费托管 + 少量 API 费。
- **时间**：第一个站 3-7 天（ChatGPT 生成代码可大幅加速）；迭代玩法每周 1-2 天。

## 可行性：4/5

三个确定性支撑：**① 情绪价值时代**（消费降级但需要爽感，付费意愿被韩国数据验证）；**② AI 大幅降门槛**（鼻祖用 GPT 搭，个人轻松复制）；**③ 已验证流量**（虎嗅/抖音都在跟进，赛道处于爆发期，还没卷出垄断者）。唯一要做的不是技术，是**找到一个别人没做的「假场景」或做得更细腻**。

## 实操步骤

1. **选题**：做一个「假装点什么」最戳你的场景（假点外卖、假购物、假开箱、假抽卡…），观察同赛道竞品找到空白。
2. **MVP**：用 ChatGPT/Claude 生成静态页 + 交互代码，免费部署到 Vercel/Pages，2-3 天上线。
3. **沉浸细节**：这是关键——凑满减、配送动画、省下的钱/卡路里计算、把 LOGO 谐音成「丑团」这类玩梗，越细腻越多人转发。
4. **接 AI 推荐**（可选）：加 LLM 生成菜品/个性化推荐，打造「选择困难症也关怀」的差异化。
5. **传播**：发抖音/小红书/B站讲「这个假装点外卖的网站爽爆了」，用「省钱 + 忍住不买」的话题引爆。
6. **变现**：挂广告 + 加打赏入口 + 观察数据，回报稳定后复制变体站群。

## 风险与坑

- **概念红利期有限**：多巴胺网站在韩国爆发后，模仿者已快速出现，同质化是最大风险——必须靠题材/沉浸度/传播差异化。
- **变现天花板**：纯广告 + 打赏的客单价不高，单站月入有限，要靠矩阵和玩法迭代放大。
- **『教人自欺』的争议**：部分评论批评这是「自欺欺人」，做好预期管理，定位成「解压玩具」而非「省钱工具」。
- **成瘾争议**：长期用可能强化消费渴望（虎嗅也提到这点），保持工具而非诱导定位。
- **跟风过气**：这波热度可能回落，务必在窗口期内快速测出爆款玩法并复制。
