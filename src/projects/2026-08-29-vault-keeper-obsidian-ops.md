# Vault Keeper：Obsidian 自动运维插件，断链/孤儿/空笔记一扫描清

> **中国独立开发者仓库：[github.com/mingdasen/vault-keeper](https://github.com/mingdasen/vault-keeper)**——你的 Obsidian vault 自动运维员。定时后台扫描，检测断链 / 孤儿笔记 / 空笔记，生成健康报告。**只读扫描，绝不自动修改你的笔记。**

## 是什么

用 Obsidian 记笔记的人（尤其做 PKM 的知识工作者）都有一个共同痛点：**库越用越大，断链、孤儿笔记、空笔记越来越多**——笔记之间相互用 `[[wikilink]]` 引用，一旦改名、删除、搬移，链接就断了；有些笔记没有任何入链、躺在角落永远不被想起来；还有些只有标题没内容。

Vault Keeper 是一个后台运维插件：**定时扫描**（默认每 60 分钟），检测三类「库存问题」：
- 🔗 **断链**：指向不存在笔记的 wikilink / markdown link
- 🏝️ **孤儿**：无入链且不在入口目录的笔记
- 📄 **空笔记**：只有标题没有内容

综合算一个 **健康分 0-100**，写入 `reports/YYYY-MM-DD.md`，可配置入口目录白名单。**纯只读**：只扫描 + 写报告，绝不碰你的笔记——零风险。作者的调研结论很关键：**官方市场内此品类空白**（现有工具全是「对话式 AI」，没有「自动后台运维」）。

## 商业模式

**Obsidian 插件生态的清品类机会。** 定位极其精准——「**对话式 AI 之外，没人做自动运维**」。用开源免费版积累社区口碑与装机量（Obsidian 官方市场品类空白 = 先发度极高），再通过增强版功能、赞助和定制服务变现。Obsidian 用户付费意愿与工具属性和 Notion 等相近，插件订阅/一次性买断是成熟路径。

## 变现方法

- **开源免费版引流**：核心扫描功能免费，打出「Obsidian 自动运维第一插件」口碑，快速占品类心智
- **增强版付费（一次性买断 ~$10-15 或 $2-3/月）**：批量一键清理（自动修复断链、合并孤儿、删空笔记）、多库健康报告、云端趋势统计、自定义清理规则
- **Buy me a coffee / GitHub Sponsors**：早期不管怎么先收一波支持
- **接企业/重度用户定制**：Obsidian 重度用户（自由职业者、研究者、作家）愿为批量整理/迁移付费
- **后续生态延伸**：同品类主题、笔记整理套装、模板市场分成

## 门槛

**低。** 技术是标准 Obsidian 插件开发（manifest.json + main.ts + styles.css），核心扫描逻辑（遍历文件、解析 `[[wikilink]]`、判断入链）是基础 TypeScript 功夫。真正的门槛不在技术，在**抢先占据这一品类空位 + 做好社区口碑与评测**。

## 所需技能

- **TypeScript** + Obsidian Plugin API（command palette、定时器、文件系统）
- **Markdown wikilink / 链接解析、文件遍历与图分析**（判断孤儿=反向引用为空）
- **UI**：健康报告的可视化（分数、明细表）
- **社区运营**：官方市场提交、写 README/视频演示、混 Reddit r/ObsidianMD 与官方 Discord

## 变现周期

**1-3 个月。** 免费版先做出来就能在社区走量，口碑上来后增强版/赞助就开始进账。品类空白意味着「第一个被记住的」能最快看到回报。

## 投入成本

**很低。** 纯时间投入（几周到一两个月业余时间可完成核心版），无服务器/云成本（本机运行）。支付/发布靠 Obsidian 官方市场 + 常见赞助渠道。

## 可行性

**4/5。** 痛点真实高频（用 Obsidian 久了库存必乱）、技术门槛低、品类空白先发优势明显、Obsidian 社区活跃且付费意愿尚可。风险是插件市场整体变现天花板有限，宜作为「口碑 + 口碑带来的定制流量」而非「纯靠插件暴富」。

## 实操步骤

1. 装 Obsidian 开发者工具（Barefoot Developer / hot-reload 插件），搭插件骨架
2. 实现核心扫描：遍历 vault → 收集所有笔记与 `[[链接]]` → 找出断链；反推入链找孤儿；识别空笔记
3. 加健康分计算 + 报告写入 `reports/` + 定时扫描（60 分钟）
4. 充分测试（作者有 17 个单元测试，值得参考)——只读是底线，绝不能误改用户笔记
5. 提交 Obsidian 官方市场 + 写 README（强调「只读零风险」卖点）+ 录 1 分钟演示视频
6. Reddit r/ObsidianMD、官方 Discord、B 站/知乎（中文社区）同步推广
7. 观察反馈后推增强版（批量清理等付费项）

## 风险与坑

- **只读底线**：任何自动修改都可能激怒用户或造成数据问题——付费「批量清理」功能也要默认关闭/二次确认
- **品类天花板**：插件市场本身单价低、总量有限，靠它做口碑与定制流量而非主营业务
- **官方市场审核**：刚起步可能手动安装，需耐心走审核
- **安全/隐私**：vault 是用户核心资产，扫描逻辑与权限边界要清晰
