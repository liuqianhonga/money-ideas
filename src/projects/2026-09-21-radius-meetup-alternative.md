## 项目是什么

**Radius** 是一个Meetup.com的免费替代方案，由开发者Jamie W.在HN上Show HN后重新发布。核心功能：

- 创建和管理社区群组
- 发布线下/线上活动
- "Activities"功能：轻量级临时聚会（如"周一早上咖啡骑行"）
- 基于地理位置的发现和参与
- 完全免费（50人以内群组）

技术栈：Ruby on Rails + 前端React

## 怎么赚钱

### 变现路径拆解

**路径1：SaaS订阅（核心）**
- 免费版：≤50成员，基础功能
- Pro版：$10-20/月，无成员上限、高级分析、优先支持
- 盈利逻辑：Meetup抽成15-20%，Radius零抽成定价更低

**路径2：迁移服务费**
- 帮现有Meetup组织者迁移到Radius
- 一次性收费$100-500（数据导出、活动重建、成员邀请）
- 市场需求：Meetup用户厌倦高费率

**路径3：企业定制版**
- 为大型企业/组织提供私有化部署
- $5000-20000一次性 + 年费

## 为什么能赚钱

### 市场需求验证
- Meetup已收取组织者15-20%活动费，用户怨声载道
- Radius Show HN获得71分、28条评论，证明需求真实
- 作者原计划"再做2年"，显示产品-市场匹配度足够

### 差异化优势
| 对比项 | Meetup | Radius |
|--------|--------|--------|
| 组织者费用 | 15-20%抽成 | 0% |
| 会员上限 | 无限制 | 免费版50人 |
| 透明度 | 算法隐藏活动 | 按地理位置自然展示 |
| 广告 | 有 | 无 |

### 中文市场机会
- 国内类似产品：活动行（有抽成）、豆瓣同城（已衰落）
- 小红书/即刻等社区缺乏活动组织工具
- 可做"垂直行业版"：程序员 meetup、户外爱好者、读书会

## 实操步骤

### 从零开始行动清单

**第一阶段：MVP验证（2-4周）**
1. 选择细分领域（如：本地编程 meetup、跑步群、读书会）
2. 用现成工具快速搭建：
   - 选项A：Wordpress + The Events Calendar插件
   - 选项B：Bubble.io无代码平台
   - 选项C：直接用Notion + Calendly组合
3. 邀请20-30个种子用户测试

**第二阶段：产品化（1-2个月）**
1. 如需开发独立平台：
   - 技术选型：Ruby on Rails / Next.js / Django
   - 核心功能：群组管理、活动发布、RSVP、地理位置
   - 支付接入：Stripe/Paddle（国际）或 支付宝/微信（国内）
2. 定价策略：
   - 免费版：≤50人，基础功能
   - 付费版：$5-10/月或 ¥30-60/月
3. 获取种子用户：
   - 从Meetup搬运活跃群组
   - 在V2EX/掘金/即刻发推广帖

**第三阶段：变现放大（3-6个月）**
1. 推出"迁移服务"：帮Meetup用户搬家
2. 推出企业版：面向公司团队活动
3. 考虑订阅制SaaS融资或独立盈利

### 具体启动建议

**低成本启动方案（推荐）：**
```
Day 1-3: 用Notion搭建群组管理模板
Day 4-7: 在本地Facebook小组/微信群发布招募
Day 8-14: 手动组织第一次活动，验证流程
Day 15-30: 根据反馈迭代，考虑是否开发独立产品
```

## 风险与坑

### ⚠️ 主要风险

1. **网络效应门槛**
   - 活动平台需要双边用户（组织者+参与者）
   - 冷启动困难，需要精准切入细分市场
   
2. **Meetup护城河**
   - Meetup已被WeWork收购，有资源反击
   - 已有数百万活跃用户迁移成本高

3. **变现周期长**
   - SaaS订阅需要积累到一定规模才盈利
   - 免费用户转化付费率通常5-15%

4. **合规风险**
   - 处理用户数据需符合隐私法规
   - 活动组织可能涉及安全责任

### 💡 降低风险建议

- 不要一开始就做"通用平台"，选垂直细分
- 先做服务（迁移帮助）验证需求，再做产品
- 考虑开源核心功能，靠高级功能/服务赚钱
