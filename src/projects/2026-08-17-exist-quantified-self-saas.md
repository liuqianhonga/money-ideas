## 是什么

[Exist](https://exist.io/)（HTTP 200 验证）是一个**个人数据分析 SaaS**：把用户各个应用服务的数据（Fitbit、Apple Watch、GitHub、Twitter、Moves 等）汇总到一处，自动分析并发现「你自己都没注意到的趋势和关联」——比如「你周一的工作效率与睡眠质量的关系」「跑步后心情的变化」。

两位创始人 Belle（iOS 工程师，曾在 Buffer 做运营）和 Josh 从 2013 年量化自我运动兴起时就开始做，起初是副业，后来全职。**目前两人公司月收入约 $14,000（约 ￥9 万），足够支付两人全职薪水**。产品没有免费版，试用 30 天后要么付费（$6/月、$57/年）要么删除账户，非常干脆。

## 商业模式

**纯订阅制 SaaS**：
- 免费试用 30 天（需绑定信用卡，提高注册门槛但转化率更高）
- $6/月 或 $57/年（无分层定价，简单直接）
- 没有免费版、没有广告、不做企业版

## 变现方法

1. **订阅收入**（唯一收入）：$6/月 × 数千付费用户 ≈ $14,000 MRR
2. **推荐链接**：60 天免费试用推荐码（推荐人获得更长试用/口碑传播）
3. **未来空间**：匿名数据洞察报告、健康/运动品牌合作（尚未展开）

## 门槛

- **技术门槛**：中。多平台 API 集成（Fitbit/Apple Health/GitHub/Twitter）+ 数据关联分析引擎，2 人可完成但需要持续维护
- **资金门槛**：低。服务器成本按用户量线性增长，起步几百元/月
- **资质门槛**：无（但涉及个人健康数据，隐私合规要注意）

## 所需技能

- 全栈开发（Web + iOS/Android，响应式 Web 起步即可）
- 第三方 API 集成与数据建模
- 内容营销（上线前做 Landing Page + 邮件列表 + 博客）
- 社区运营与用户信任建设（公开路线图、公开收入统计）

## 变现周期

**6-12 个月**。从 2013 年 6 月开始做，11 月有 beta 用户，2014 年 2 月众筹预购、4 月公测才第一次赚钱。内容营销铺垫期长，但一旦量化自我赛道起风，增长会加速。

## 投入成本

- 资金：服务器 + Stripe 抽成，起步每月几百元
- 时间：MVP 3-6 个月（兼职），全职后 6-12 个月见稳定收入
- 关键：**上线前就做内容营销**（创始人强调「在发布产品之前先开始做营销」），Landing Page + 邮件列表是第一批用户来源

## 可行性

**4/5**。赛道真实（量化自我/个人数据分析需求持续存在），订阅模式干净，2 人可做。但依赖第三方 API 生态（Jawbone 倒了、Instagram 改 API 都直接伤害产品），且冷启动周期长。

## 实操步骤

1. **验证需求**：去量化自我社区（Quantified Self 论坛、Reddit r/QuantifiedSelf）、健康追踪用户群，看大家怎么手动整理数据
2. **选最小数据源**：先接 2-3 个数据源（Apple Health + 一个运动 App + GitHub），做「自动关联分析」的 MVP
3. **上线前 2 个月开始内容营销**：Landing Page + 邮件列表 + 博客（写量化自我、数据习惯类文章）
4. **用众筹/预购验证付费意愿**：像 Exist 一样做早期支持者年付预购（$50-100/人），既筹钱又验证需求
5. **坚持无免费版**：试用必须绑卡，宁可注册少也要注册质量高
6. **透明度建立信任**：公开收入统计、公开路线图、用户投票决定功能优先级、个人邮箱直接沟通
7. **内容转载获客**：把博客文章投给 Lifehacker、Fast Company、Zapier 等大站转载（创始人验证过：峰值月 33,000 独立点击）

## 风险与坑

- ⚠️ **API 依赖风险**：第三方平台倒闭（Jawbone）、改 API 政策（Instagram）直接伤害产品，创始人策略是分散负载、不把鸡蛋放一个篮子
- ⚠️ 冷启动周期长：内容营销铺垫 6-12 个月才有规模效应
- ⚠️ 隐私合规：个人健康数据敏感，GDPR/国内个保法都要注意
- ⚠️ 绑卡试用门槛高：注册量少，如果内容渠道没跑通会很难看
- ⚠️ 数据质量问题：不同来源数据质量参差，等于在给其他公司做客服
