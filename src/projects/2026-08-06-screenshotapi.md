## 是什么

ScreenshotAPI 是一个网页截图 API 工具：开发者通过简单 API 调用即可生成网页截图，用于新闻目录、报告、社交卡片等场景。

## 怎么赚

- **Freemium SaaS**：免费版每月 100 张截图 + 付费版 $9-$175/月
- 20 个付费用户中 13 个来自谷歌广告（关键词 screenshot API，$100/月投放）
- 涨价只针对新客户，老客户维持原价 → 流失率很低

## 核心打法

1. **自己解决痛点**：不想花 $35/月买现成的 → 自己做 → 做成产品卖
2. **模仿竞争对手**：用 Ahrefs 看对手流量来源和反向链接，照做
3. **谷歌广告精准获客**：小预算 $100/月，但 ROI 极高（13/20 用户）
4. **稳定低价策略**：刚上线定价 $5 太便宜，涨到 $9 起（太便宜没人认真对待）

## 行动建议

- 「自己需要的工具」是最可靠的创业起点（Dogfooding）
- 用 Ahrefs/SimilarWeb 逆向研究竞品流量渠道，直接模仿有效手段
- API 类产品小而美：低流失率 + 稳定增长，$1000 MRR 就能支撑全职

## 风险

- 谷歌广告成本会上升，需同时做 SEO 降低依赖
- 截图 API 竞争激烈（Browserless/urlbox 等）
