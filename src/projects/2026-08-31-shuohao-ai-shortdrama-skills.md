# shuohao-skills：把 AI 短剧『小说→分镜成片』全流程 Agent 化——短剧爆发期的工业化量产机会

> **AI工具集 2026-08-28 + [GitHub 2439 star](https://github.com/eternityspring/shuohao-skills)（Apache-2.0）：** shuohao-skills 是**开源的 AI 短剧制作 Skill 集合**，专为 Claude Code / Codex 等 Agent 设计，提供从**小说改编大纲、角色设定、美术设定、剧本撰写到分镜切分**的完整工作流，每个环节配有脚本化质量检查，确保角色不雷同、时长精准、风格一致。它踩中的是**AI 短剧已经进入规模化爆发期**这个确定风口。

## 是什么

shuohao-skills 是一套**开源的 Agent Skill 集合**，把「AI 短剧制作」拆成一条标准的工业化流水线：

1. **改编大纲**：小说/网文 → 改编成短剧大纲
2. **角色设定**：拆解角色，确保角色不雷同、有人设
3. **美术设定**：场景与道具设定、美术风格统一
4. **剧本撰写**：写成适合短剧节奏的剧本
5. **分镜切分**：切分镜、配画面提示

每个环节都有**脚本化质量检查**（角色一致性、时长精准、风格统一），运行在 Claude Code / Codex 里。它的价值不是某一个模型，而是把「短剧生产」变成**可批量、可复制的 Agent 流水线**——这正是当下短剧市场最缺的能力。

背景信号：**AI 漫剧、短剧赛道已进入规模化爆发期。仅抖音端，2026 年上半年新上线的 AI 剧、漫剧就达到 22.19 万部**。有人已经用「一句话实现 AI 短剧批量生成」的工具在量产。而 shuohao-skills 把这套生产能力**开源 + Agent 化**，个人可以免费拿到手。

## 商业模式

shuohao-skills 本身 Apache-2.0 全开源,但它指向一个**正在爆发的、需要「工业化量产」能力**的内容赛道：

- **AI 短剧是确定风口**：抖音半年新增 22.19 万部 AI 剧/漫剧，说明平台已为 AI 短剧开闸、有分账/流量机制。内容是短视频生态的刚需，AI 让制作成本骤降，但**「批量、稳定、高效地生产」能力稀缺**——正是这套 Skill 解决的事。
- **代工/代运营**：很多网文作者、短剧机构有内容但不会做 AI 短剧，个人可代工（按成片/集数收费）或代运营账号。
- **一站式短剧工作室**：拿开源 Skill 自建「AI 短剧生产工厂」——改编 + 生成 + 配音 + 成片，批量供给抖音/快手/小程序短剧分账。
- **定制/周边**：为特定需求定制 Skill、搭建工作流、做 Agent 部署，收定制费。

## 变现方法

1. **AI 短剧代工**：按集/按成片收费，承接网文作者、短剧机构、MCN 的批量改编需求。
2. **账号运营 + 分账**：自建账号稳定量产 AI 短剧，吃平台短剧分账与流量收益。
3. **一站式服务**：把「改编→分镜→生成→配音→成片」打包成短剧工作室服务。
4. **培训/教程**：教别人跑这套 Agent 流水线，收培训费。
5. **Skill 定制**：给机构和团队部署定制化 Agent 工作流。

1. 拉取开源 Skill：`https://github.com/eternityspring/shuohao-skills`，在 Claude Code 或 Codex 里按文档跑通一条完整流水线（小说 → 大纲 → 角色 → 剧本 → 分镜）。

## 风险与坑

- **内容同质化**：AI 短剧量产容易同质，需靠题材筛选与内容判断力拉开差距（Skill 提供了质检机制，但选题能力在人）。
- **耗额度/耗时间**：Agent + 视频生成都在烧 token/额度，要控制成本、提高单条成片效率。
- **平台规则波动**：短剧分账/流量算法会变，要紧跟平台政策。
- **合规**：短剧题材要合规，规避违禁内容与版权改编风险。
