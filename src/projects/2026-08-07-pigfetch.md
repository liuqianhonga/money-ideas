## 是什么

PigFetch 是一款 Windows 视频下载工具：粘贴视频链接 → 选择画质 → 下载。支持 B站、抖音、快手、小红书、微博、AcFun、今日头条等 2000+ 站点，可选择 4K/1080p/720p 画质或仅音频，下载无水印原始画质。免费模式是注册即送 100 次下载，用完可开通会员解锁无限下载。v1.5.7，安装包 96.4MB，支持在线升级，Windows 7/8/10/11 全兼容。

产品来自 chinese-independent-developer 仓库（60.5k star 的中国独立开发者项目大全），官网可访问。

## 商业模式

**Freemium + 会员订阅**：注册免费送 100 次下载（低门槛体验），会员解锁无限下载。这是工具类产品最经典的变现模型——「免费拉新，付费解锁」。

## 变现方法

- 会员订阅/买断：核心收入，按周/月/年或终身买断定价
- 提升转化钩子：100 次免费正好「够清空整个收藏夹」，用完即触发付费决策点
- 后续可加：批量下载、4K 专属、云端存储等会员权益分层

## 门槛

- 技术：中——需要 Windows 桌面客户端开发 + 各平台视频解析接口维护（这是持续成本，平台一改版就要跟进）
- 资金：代码签名证书（几百元/年）、服务器、推广
- 资质：无硬性资质，但涉及版权合规风险（见风险）

## 所需技能

- 桌面应用开发（Electron/Tauri/C#）
- 视频站点解析/反爬对抗经验
- 支付集成（国内支付宝/微信，海外 Stripe）
- 产品营销（工具类靠口碑 + 应用商店/下载站分发）

## 变现周期

MVP 1-2 个月，第一批付费用户 2-4 个月（工具类转化快，但需流量积累）。

## 投入成本

- 资金：1-3 万元（签名证书、服务器、推广预算）
- 时间：持续维护是重点，初期开发 1-3 个月，后续每月 10-20 小时维护

## 可行性评分

**3/5**。模式已验证（同类工具 IDM/唧唧Down 等证明付费意愿），但竞争激烈 + 版权合规风险是硬约束，个人做需选准细分（如小红书/快手下载的空白点）。

## 实操步骤

1. 调研需求：确认目标平台的下载工具缺口（如小红书无水印下载）
2. 技术验证：先做 CLI 版解析器（Python 原型），确认能稳定解析目标站点
3. 产品化：用 Tauri/Electron 包成桌面应用，加画质选择、批量下载
4. 免费试用 + 会员付费墙，接支付
5. 分发：下载站、贴吧/QQ 群、B站教程视频引流
6. 建立更新机制：解析规则随平台改版迭代（用户流失风险点）

## 风险与坑

- **版权风险**：下载他人内容可能侵权，产品需明确「仅限个人学习合法用途」并做好免责（本产品已声明）
- 平台对抗：B站/抖音会持续改版封堵第三方下载，维护成本高
- 竞品多：免费/开源替代品存在，需靠体验（无水印、画质、速度）差异化
- 杀软误报：未签名的下载工具常被 Windows Defender 拦截，务必买代码签名证书
