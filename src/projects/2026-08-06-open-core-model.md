## 是什么

这是一个「模式项目」：开源免费 + 商业增值（Open Core）是被反复验证的独立开发者商业路径。今天收集的项目里 Doka.js（开源 FilePond 引流）、Prelint、SKI 都是这个模式。

## 怎么赚

- 开源核心免费 → 大量开发者试用 → 高级功能/云服务/企业授权收费
- 核心杠杆：开源社区帮你测试、推广、建立信任
- 变现层：SaaS 托管版、高级功能、企业许可证、支持服务

## 核心打法

1. **免费开源引流**：GitHub Star = 品牌资产，开发者社区是最高质量用户群
2. **商业增值层**：托管版（不用自己部署）/高级功能/企业支持
3. **案例验证**：FilePond→Doka、ESLint→商业版、Redis→云服务

## 行动建议

- 做开发者工具优先考虑 Open Core 模式：开源版积累用户，商业版赚钱
- 关键设计：开源版足够好用但不完整，商业版解决「懒得自己搞」的痛点
- GitHub Action/CI 集成增加粘性，企业版满足团队需求

## 风险

- 大厂可能基于开源版做免费替代
- 开源社区维护成本不低（issue/PR 处理）
