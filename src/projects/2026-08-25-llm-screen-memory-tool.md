# LLM 屏幕记忆工具：把「我这一天干了啥」变成 Agent 能读的工作记忆（ambient-context 商业化）

> **Show HN 开源 [ambient-context](https://github.com/dragthelake/ambient-context)（51 赞）：一款 macOS 菜单栏 App**，通过无障碍 API 每几秒读取你聚焦窗口的文本，写成纯 markdown 日档（无截图、无视频、不留本地以外）。把你每天的工作轨迹变成 AI Agent 能直接读的「记忆文件」——问 Claude Code「我周二干了啥」它能答，还能帮你写站会更新、建项目记忆。当 Agent 越来越强但「没有私人上下文」时，**「LLM 记忆层工具」成了新的效率刚需**。

## 是什么

我们在本地跑 Claude Code、Codex、Cursor 这些 Agent，但**它们默认不认识「你」，因为没你的上下文**。传统记忆方案大多靠截图/录屏（重、隐私重、文件大）或手动写（费事、坚持不住）。ambient-context 换了个思路：**只读聚焦窗口的文本（无障碍树），轻量地去重、过滤界面噪音、脱敏密钥，写成一个小而全的 markdown「日档」**，Agent 读它就有「你昨天/上周干过什么」的上下文。

对个人开发者是「效率小工具」，但它的本质是：**给 AI 建立持久工作记忆的基建**——这恰好是 Agent 时代被反复提及的「memory」痛点，正是产品化金矿。

## 商业模式

**工具型产品，免费核心 + 付费增值**。开源版（自建、无公证版本）攒技术圈口碑，商业化靠**正式签名/公证的下载版收费**或 **Pro 订阅**（高级过滤、多设备/团队、云端可选、与更多 Agent 框架深度集成）。类比：Obsidian 免费核心 + Sync/付费插件模式成立，说明「本地优先效率工具」能靠增值付费活下来。

## 变现方法

- **正式版买断/订阅**：把开源自建版之外做成「下载即用」的签名版，按买断 ¥98 或订阅 ¥15/月
- **Pro 高级功能**：跨应用聚合、脱敏规则自定义、生成站会/周报模板、团队共享
- **Agent 记忆托管/同步**（后期）：同步加密记忆库，按存储/席位收费
- **生态集成**：与 Claude Code/Codex 的插件/技能包联动，间接变现或分成
- **企业采购**：给团队统一装「Agent 记忆规范」，B2B 授权

## 门槛

**中。** 桌面开发（macOS/Apple Silicon）+ 无障碍权限 + **隐私安全设计**（本地处理、不采集密码管理器/私密浏览、密钥脱敏）是硬门槛，需要一定的技术功底。但一个人深耕这类小工具完全可行——ambient-context 本身就是个人 + 开源做出来的。

## 所需技能

- **macOS 桌面开发**：Tauri（Rust/Node）或 Swift，能做菜单栏常驻 App、无障碍树读取
- **隐私与安全工程**：本地处理、输入脱敏、不越权读取，这在「AI 读你屏幕」场景是信任命门
- **App 分发与公证**：Apple 开发者账号、签名、公证、更新通道
- **独立开发与增长**：Show HN/PH/技术社区冷启动、收割早期用户反馈

## 变现周期

**3-6 个月。** 先开源攒口碑与用户，再发签名版收费；第一个付费用户可能 1-3 个月（技术圈对「给 Agent 记忆」买单意愿上升），稳定订阅需 3-6 个月。

## 投入成本

低。主要是**时间**。中期 <¥2000（Apple 开发者账号年费 ¥688、Tauri/云同步成本）即可上线收费版。纯个人时间投入，现金风险极低。

## 可行性：3/5

## 实操步骤

1. 先把 ambient-context 这类开源项目跑起来，理解无障碍树读取 + markdown 日档格式
2. 自己用核心功能 2 周，记录「Agent 真的能用它干活了」的体验，明确差异化（如更强的脱敏、跨 App、更小的文件）
3. 发一版签名的收费版（或 Pro 模式），定价并做落地页
4. Show HN / X / 技术周刊 / PH 发布，掏典型案例：「让 Claude 读你的项目记忆写站会」
5. 收早期用户反馈，加 Pro 功能与团队/协作选项
6. 接少量付费用户验证，再决定扩生态（Agent 插件/企业）

## 风险与坑

- **隐私信任是双刃剑**：产品卖点就是「AI 读你的屏幕」，一旦有泄露事故或信任危机直接崩盘——必须在代码与宣传层面做到本地优先、可审计
- **隐私权限收紧**：OS 收紧无障碍/屏幕读取权限会抬高维护成本
- **「记忆」需求是否足够付费**：个人工具可能「很好用但不愿付费」，需靠 Pro/企业/生态变现对冲
- **竞品增多**：「Agent 记忆」热，之后会有团队/大厂下场，要尽早建立品牌与隐私口碑
