## 是什么

OpenShorts（开片）是一个短视频一键生成工具。用户输入一个话题，系统自动完成：
- 脚本生成（LLM）
- 画面匹配（素材库检索）
- 配音（TTS）
- 字幕烧录（SRT/ASS）
- 成片输出 + 发布文案（SEO 关键词）

面向两类人：
1. **短视频创作者**：想批量出内容但没时间剪片
2. **出海营销/电商团队**：需要多语言、多平台、多版本短视频

## 商业模式

- **工具订阅制**：月费/年费，含 N 条成片额度
- **单次成片付费**：按条卖（针对低频用户）
- **API 抽成**（未来扩展）：面向营销公司/代理商提供 API 批量生成

核心逻辑：把"从话题到成片"的 2-3 小时人工压缩到 5 分钟自动化，卖时间差。

## 变现方法拆解

1. 免费额度（1-3 条/月）做钩子，转化付费订阅
2. 企业版：多账户 + 品牌资产库 + API 访问，按月收费
3. 素材授权包：把优质 BGM/画面素材打包卖
4. 平台代理：给 MCN/代理商做"内容工厂"白标版

## 门槛

- **技术门槛**：需要 LLM 编排（脚本生成 + 关键词提取）、音视频合成（ffmpeg）、素材检索（向量库）
- **内容门槛**：素材库的版权和丰富度决定上限
- **资质门槛**：无硬性资质，但要注意 BGM/画面的版权

## 所需技能

- LLM 应用开发（prompt 工程 + 编排）
- ffmpeg / 音视频处理
- 向量检索（素材匹配）
- 短视频运营经验（理解"什么钩子有效"）

## 变现周期

- MVP（基础脚本+配音+字幕）：2-4 周
- 有稳定订阅：2-3 个月（素材库质量 + 获客）

## 投入成本

- 服务器 + LLM API + TTS API：约 ¥500-1500/月
- 素材版权库：¥5000-30000 一次性（或持续授权费）
- 开发时间：1-2 个月（个人兼职）

## 可行性（4/5）

- 赛道热度：短视频自动化 2025-2026 年持续升温，多语言出海是强需求
- 竞争：CapCut 等大厂在做但重人工；开片这类轻量自动化工具是差异化空间
- 变现路径清晰，用户付费意愿已验证（出海营销团队月预算 1000-10000）

## 实操步骤

1. 选 1-2 个垂直场景（如：电商商品短视频、知识科普）
2. 搭 MVP：LLM 脚本 + 开源 TTS + ffmpeg 合成 + SRT 字幕
3. 建素材库：CC0 素材 + 自制 10-50 条画面
4. 发布到 Product Hunt / V2EX 分享创造 / 小红书（短视频创作者）
5. 定价：免费 3 条/月，付费 ¥99/月起
6. 收集 10 个付费用户后再做企业版

## 风险与坑

- **版权风险**：素材/BGM 用错会被平台下架，必须用 CC0/授权素材
- **同质化**：工具多了之后"一句话出片"不再是卖点，要往"出片质量 + 多语言"卷
- **API 成本**：LLM + TTS 成本随用量上涨，需要缓存 + 批量优化
- **平台政策**：YouTube/TikTok 对"低质批量内容"会限流，工具要强调"人审+个性化"
- **竞品下沉**：CapCut/剪映 2025-2026 持续推 AI 功能，个人工具要卡位"出海多语言 + 定制"
