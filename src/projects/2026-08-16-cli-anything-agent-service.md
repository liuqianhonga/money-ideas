## 是什么

[CLI-Anything](https://github.com/HKUDS/CLI-Anything) 是港大数据实验室（HKUDS）开源的项目：**让所有软件 Agent 原生**。核心思路是给 GUI 软件（Photoshop、Excel）、开发者工具、Web 平台、SaaS 提供统一的 CLI 封装层，让 Claude Code / Cursor 等 AI Agent 能直接通过命令行操作这些软件，而不必依赖脆弱的不稳定 GUI 自动化。

配套的 [CLI-Hub](https://clianything.cc/) 是一个 Agent 友好 CLI 注册表，可以搜索、安装、启动各类软件/平台的 CLI 封装。项目上线即冲到 GitHub Trending 榜首，目前 **⭐47k / 4.7k fork**，说明「让 Agent 能用更多软件」是开发者和企业共同的刚需。

## 商业模式

**开源引流 + 企业服务变现**：

- 开源项目本身免费，靠 47k star 建立信任和流量入口
- 变现点在「企业 Agent 化改造」：企业想把内部 SaaS/ERP/设计工具接入 Agent 工作流，但自己不会做 CLI 封装 → 找外部开发者定制
- 围绕 CLI-Hub 的生态工具（搜索增强、监控、批量管理）也可以卖

## 变现方法

1. **企业 CLI 封装定制**（核心）：接单帮企业把特定软件（财务系统、CRM、内部工具）做成 Agent 友好 CLI，报价 ¥5k-50k/项目
2. **Agent 迁移咨询**：帮企业评估「哪些软件可以 Agent 化、怎么接」，出方案收咨询费
3. **CLI-Hub 生态工具**：做 CLI 包管理器增强、兼容性检测工具，SaaS 订阅
4. **教程/课程**：录「把你的软件变成 Agent 原生」课程，面向开发者和企业

## 门槛

- **技术门槛**：中。需要 CLI 开发（Python/Go）、了解各软件 API/自动化接口；不要求自研大模型
- **资金门槛**：低。做服务不需要服务器大额投入
- **资质门槛**：无

## 所需技能

- Python/Go CLI 开发
- 熟悉 1-2 个 Agent 框架（Claude Code、Cursor、Codex）
- 理解软件自动化（Selenium/API 调用/命令行工具）
- 商务沟通能力（接企业单）

## 变现周期

1-3 个月：先自己用 CLI-Anything 封装 2-3 个常用软件做案例，再对外接单。

## 投入成本

- 资金：基本为零（开发机即可）
- 时间：学习封装 2-3 周，接单后每单 1-4 周

## 可行性：4/5

理由：① 47k star 证明需求端真实存在（Agent 要用更多软件）；② 大厂（Cursor/Claude）都在推 Agent 操作软件，方向长期确定；③ 个人开发者即可提供「封装服务」，不需要大团队；④ 已有 CLI-Hub 注册表生态，可以挂靠流量。

## 实操步骤

1. 克隆 CLI-Anything，跑通 2 个示例封装（如 Excel、浏览器）
2. 用 Claude Code 实测「通过 CLI 操作软件」的体验，形成案例
3. 选 3 个高频企业软件（财务/CRM/设计），做出封装并发布到 CLI-Hub
4. 写技术博客/发 V2EX、即刻：「如何让 Agent 操作你的企业软件」
5. 在小红书/朋友圈/企业微信群发布「Agent 化改造服务」广告
6. 接第一单（建议从 ¥5k 起步），交付后沉淀成标准化模板
7. 复购和转介绍 → 按行业复制

## 风险与坑

- ⚠️ **封装质量参差**：不同软件 API 稳定性不同，交付前必须充分测试
- ⚠️ **企业决策链长**：To B 单子周期长，先从小企业/个人工作室切入
- ⚠️ **开源项目本身可能转向**：CLI-Anything 是大学实验室项目，长期维护依赖社区，做生态工具时留意版本兼容
- ⚠️ 竞品：各大厂可能官方出 Agent 兼容层，保持跟进、差异化在垂直行业
