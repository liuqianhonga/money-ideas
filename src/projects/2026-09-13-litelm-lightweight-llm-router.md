# Litelm — LiteLLM 轻量替代方案

## 是什么

Litelm 是一个精简版的 LiteLLM，专注于核心的 LLM 路由和消息格式转换功能，去掉了代理服务器、缓存层、成本追踪等90%的冗余代码。

**核心功能**：
- 统一调用接口：`litelm.completion("openai/gpt-4o", messages=[...])`
- 支持 19 个提供商：OpenAI、Anthropic、Groq、Mistral、xAI、Azure、Bedrock 等
- 流式输出、工具调用、Embeddings、文本补全
- API 完全兼容 LiteLLM，替换 import 即可切换
- 仅 2900 行代码，2 个依赖（openai、httpx）

**GitHub 数据**：157 points，52 comments，Alpha 阶段，262 个测试通过

## 风险与坑

### 技术风险
- **提供商 API 频繁变更**：需持续跟进 OpenAI、Anthropic 等更新
- **兼容性问题**：不同模型的消息格式差异可能导致意外错误
- **性能瓶颈**：高并发时的路由延迟需要优化

### 商业风险
- **LiteLLM 官方优化**：如果官方推出精简版，竞争力下降
- **大厂垄断**：OpenAI/Google 可能推出官方聚合服务
- **价格战**：竞争对手可能免费或低价抢市场

### 法律风险
- **API 条款合规**：需确认各提供商的使用条款
- **数据隐私**：用户 API key 存储需符合 GDPR 等法规
- **责任边界**：代理服务的法律责任界定
