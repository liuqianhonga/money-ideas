# B2B 内容代写订阅：Contentellect 帮中小企规模化博客内容（真实盈利案例）

> **真实盈利案例**：两位**不会写代码**的内容营销人（Marc 和联合创始人）做的 [Contentellect](https://contentellect.com/)，帮**中小企业（SMB）规模化生产高质量博客内容**，按英文单词计费 + 包月订阅，做到平均 **$10K MRR**（约 ¥7W/月，峰值 $16K/月约 ¥11W）。Source: [Sideidea /article/53](https://sideidea.com/article/53)

## 是什么

一个 B2B 内容代写服务：客户（中小企业）知道内容营销的价值，但缺乏内部资源和时间执行，就外包给 Contentellect 帮他们写博客文章。核心服务帮客户实现三件事：**经搜索引擎增加自然流量、建立思想领导力、为销售/市场团队提供内容素材**。

## 商业模式

**按字计费 + 订阅制**。单价 $0.1/单词（1000 单词=$100），提供两种方案：「现收现付」（按需购买）和「博客文章包月」（每月固定篇数），并可升级到含策略/创意/日程/代发布的全托管服务。本质是「内容产能服务化 + 订阅锁定」。

## 变现方法

- 按字计费：$0.1/单词，透明可估算
- 包月订阅：每月固定篇数，现金流稳定、锁定长期
- 全托管服务：从纯写作升级到「策略+写作+代发布」，客单价提升
- 获客：Facebook 联盟营销群组、LinkedIn、邮件外联（hunter.io 挖掘）+ 精准小额广告
- 副渠道：在 Legiit 等自由职业市场挂牌接单
- 增值：内容策略/创意/日程管理，向更高价值服务延伸

## 门槛

**低中。** 技术上极低——盲用 WordPress + WooCommerce 三周上线。真正的门槛是**内容营销/SEO 的专业能力**以及**精准找到目标客户**。不需要代码、无硬件投入、无资质要求。

## 所需技能

内容营销与 SEO 写作、对目标行业内容需求的洞察、B2B 客户获取（群组/邮件/LinkedIn 外联）、基础 WordPress 建站。可以外包自由撰稿人控制成本。

## 变现周期

**数周。** MVP 三周上线，首月 3 客户 $2K MRR，2018 年 5→10 月四个月从 $2K 涨到 $8K MRR。

## 投入成本

**极低。** WordPress 主题 + WooCommerce 搭建，约三周时间成本；自由撰稿人按单结账、无固定雇员负担；服务器/域名等小额开销。核心投入是**时间和客户获取**。

## 可行性：4/5

## 实操步骤

1. 选定一个你懂或有人脉的垂直行业（SaaS、本地服务、医疗等），确认他们有内容营销痛点
2. 用 WordPress + WooCommerce 搭个极简 MVP（约 3 周），挂上单价与方案
3. 在目标客群聚集的社群（对应 Facebook 群组/LinkedIn/行业微信群）发布服务帖
4. 起步用现收现付接单，验证需求；自由职业者按单协作控制负担
5. 提炼「全托管」高客单价档位，把服务从纯写作升级到策略+发布
6. 建立外联 SOP（邮件/私信），配合小额精准广告，规模化获客

## 风险与坑

- 客户流失是关键挑战：新客户要 3-4 个月落地，可能 1 个月就离开——靠自由职业者+多渠道分散风险
- 内容质量决定口碑与复购，需严格把控交付
- 客群单一会放大收入波动（案例主力客户减少时 MRR 回落）
- 访客发帖（guest post）服务繁琐且利润率低，案例 2019 年果断砍掉——别贪多
- 纯内容服务天花板有限，需靠订阅+升级服务拉高客单
