## 是什么

AgentHive 是 Windows 桌面版 AI 圆桌工作台：把业务问题丢给可配置的产品、市场、反方、总结 Agent 同场推演，自动输出结论、风险点和待验证假设，用于决策压测和证据整理。

## 怎么赚

- Freemium：免费基础 + 专业版（更多角色/更复杂场景）
- 目标用户：创业者、产品经理、咨询顾问（决策前「开个 AI 会」）
- 企业版：团队知识库 + 决策记录

## 核心打法

1. **多 Agent 辩论**：红队/蓝队/反方机制让 AI 输出更可信（对抗式思考）
2. **场景明确**：决策压测——比「问 ChatGPT」多一层严谨
3. **桌面本地**：隐私友好（企业数据不出本机）

## 行动建议

- 多 Agent 协作产品（辩论/评审/圆桌）是 2026 年热点方向
- 「对抗式 AI 输出」是提高可信度的关键设计
- 可做 AI 版「外脑评审团」：创业想法压测、方案评审

## 风险

- 多 Agent 编排成本高（token 消耗）
- 用户习惯培养成本高（新交互模式）
