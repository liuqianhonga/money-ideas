## 项目是什么

Velokey 是统一 AI API 网关（Unified AI API Gateway）。它提供一个 OpenAI 兼容的单一接口，背后聚合 100+ 模型：GPT、Claude、Gemini、Flux、Kling、Veo、Seedance、Sora 等。

**核心价值**：
1. **一个 key 用所有模型** — 开发者不用分别注册各家 API
2. **按 token 付费** — 没有订阅门槛，用多少付多少
3. **比价切换** — 用户可以在模型之间实时对比价格并切换

来源：Hacker News Show HN（2026-08-04），站点 https://velokey.ai 验证可访问，页面明确「One OpenAI-compatible API for GPT, Claude, Gemini, Flux, Kling and 100+ models. Compare pricing, switch instantly, pay per token.」

## 怎么赚钱

1. **API 转售差价**：上游按官方价拿货，Velokey 加 10-30% 卖，走量
2. **月费套餐**：开发者订阅制，含一定量免费额度
3. **企业定制**：为团队提供私有网关部署（类似 OneAPI 的托管版）
4. 增值：模型路由、成本监控、用量分析仪表盘

## 为什么能赚钱

- **真实痛点**：AI 视频/图像 API 百花齐放（Kling/Veo/Seedance/Sora），开发者不想维护 5 个 SDK 和 5 个账单
- **已有验证**：同类产品 OpenRouter（文本模型聚合）已做到数百万美元 ARR；Velokey 是它的「视频+图像版」
- **国内对标**：国内类似「OneAPI」开源项目生态活跃，说明需求真实；但商业化程度低，Velokey 模式把开源项目做成了商业 SaaS
- **市场趋势**：2026 视频生成模型爆发，Kling/Veo/Sora 价格战，正是聚合层套利窗口

## 实操步骤（从零开始）

1. 用开源 OneAPI / LiteLLM 做基础聚合层（省 80% 开发量）
2. 对接 3-5 个视频模型（Kling、Veo、Seedance 起步），先跑通一个接口
3. 实现统一计费：token 计数 + 余额系统 + Stripe/支付宝
4. 做比价页面：实时展示各模型价格，这是获客钩子
5. 定价策略：每 token 比官方贵 15-25%，初期用免费额度获客
6. 发布 Show HN + Product Hunt，写「对比 5 家视频 API 价格」的 SEO 文章
7. 重点服务独立开发者和 AI 视频工具（如 Manhwa AI 这类产品），做集成案例

## 风险与坑

- 上游 API 政策风险：官方可能直接出聚合（OpenAI 已出 Responses API），要不停跟上游版本
- 价格战：比价功能是把双刃剑——用户看到更便宜的渠道会流失
- 合规：转售第三方模型 API 需查条款（部分厂商禁止转售）
- 账期风险：预充值模式有现金流压力；按量后付费会被薅
