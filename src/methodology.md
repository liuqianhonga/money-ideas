# 📚 方法论：赚钱项目收集与筛选体系

> 本站项目背后的**筛选逻辑与收集流程**，公开沉淀于此，方便回溯与复用。
> 合并自「副业商机每日推送」（biz-opportunity-daily）方法论，2026-08-06。

---

## 一、收集流程（两步：快报层 + 深度层）

```
① 抓数据：MCP biz_opportunity(48h) + GitHub Trending + 深度信源
② 过滤：黑名单机械排除 → 白名单精筛
③ 信号增强：Ask HN 宝藏线程 + 商业痛点 + 平台套利
④ 快报层：输出 4 分类副业商机快报（推 TG）
⑤ 深度层：挑 2-5 个写网站 markdown + 三维评分
⑥ 部署：build → git push → Vercel → 验证 200
⑦ 推送：一条 TG 消息（快报 + 网站链接）
```

## 三、⭐ 特别信号库

### 3.1 T0 宝藏线程（Ask HN 金矿）

| 信号 | 频率 | 价值 | 说明 |
|:---|:---:|:---:|:---|
| `Ask HN: Those making $500/month on side projects` | 每年 1-2 次 | 🔥 极高 | 真实副业成功案例合集（项目名+收入+技术栈+获客） |
| `Ask HN: What's your SaaS stack` | 周期性 | 🔥 高 | 现成技术选型参考，减少试错成本 |

### 3.2 商业痛点 Ask HN = 市场验证

Ask HN 在问「有没有人做过 X」或「Y 太贵了有没有替代品」→ **X/Y 的市场需求已被验证**，直接纳入项目池：

| 提问模式 | 副业方向 |
|:---|:---|
| `Alternative to [贵价工具]` | 做轻量替代版/迁移咨询 |
| `Has anyone deployed [AI/tech] in [行业]?` | 给传统行业做 AI 工具 |
| `How did you set up [技术方案] for [场景]?` | 个人 Agent 搭建教程/服务 |
| `Have you ever [创新用法]?` | Agent-as-a-Service |
| `What surprised you about [跨境/合规]?` | 跨境企业注册咨询 |
| `How do you [业务指标]?` | 广告分析 SaaS/咨询 |

### 3.3 平台变化 = 套利机会

大平台 UI/政策/算法重大变化创造短期套利窗口：

| 变化类型 | 套利方向 |
|:---|:---|
| 搜索引擎改版 | SEO 策略更新服务 |
| 广告政策变化 | 帮 App 做替代变现方案 |
| API/费用变化（AI 模型降价/涨价） | 成本优化咨询 |

## 五、大数据量两阶段过滤法

当原始数据 >100 条时，两阶段过滤避免全量超时：

### 阶段一：机械关键词排除（黑名单，137 → 50-80 条）

```python
exclude_kw = [
    '美联储','欧洲央行','特朗普','拜登','普京','俄乌','乌克兰','俄罗斯',
    'IPO','上市','融资丨','SPAC','涨停板','跌停板','股票','基金市场','公募',
    '央行','券商','债券','外汇','原油','油价','SpaceX','Agility',
    '英伟达','宁德时代','蔚来','理想','茅台','安踏',
    'A轮融资','B轮融资','C轮融资','近亿元',
    '教育','高考','文凭','就业','下沉',
    '手机','耳机','耳夹','体验',
    '茶饮','冰淇淋','世界杯','梅西',
]
# ⚠️ 不要用 re.search 编译 '|' 结尾的关键词（匹配空字符串导致全滤）——用纯 in 检查
keep = [i for i in items if not any(kw in i.get('title','') for kw in exclude_kw)]
```

## 六、项目筛选标准

✅ **保留**：
- 真实存在、URL 可 curl 验证的产品/服务
- 个人或小团队可复制（排除企业级/融资新闻）
- 有明确变现路径（订阅/买断/服务费/佣金/API 抽成）
- 信号型商机（如某平台关停 → 迁移服务需求）

❌ **排除**：
- 宏观/政治/灾害新闻、纯技术帖、无变现信号的资讯
- 已经吹破的项目、纯概念无实物的

## 七、拆解维度（每个项目必须全覆盖）

| 维度 | 说明 |
|:---|:---|
| 是什么 | 做什么，解决什么问题 |
| 商业模式 | 一句话说清怎么赚钱 |
| 变现方法 | 具体变现路径拆解 |
| 门槛 | 技术/资金/资质门槛 |
| 所需技能 | 需要什么能力 |
| 变现周期 | 启动到回本预计多久 |
| 投入成本 | 前期资金+时间 |
| 可行性 | 1-5 保守评分 |
| 实操步骤 | 从零开始行动清单 |
| 风险与坑 | 诚实列出风险 |
| 证据/验证 | 出处链接+验证结果 |

---

## 八、信心指数（三维评分 → 0-100）

```
confidence = 100 × (0.4×变现难易 + 0.3×实施容易度 + 0.3×门槛容易度)
```

| 指数区间 | 评级 | 建议 |
|:---:|:---|:---|
| 80+ | 💯 极佳 | 低门槛快变现，优先考虑 |
| 60-79 | ✅ 良好 | 值得投入，注意周期 |
| 40-59 | ⚠️ 一般 | 有门槛或变现慢，谨慎评估 |
| <40 | ❌ 谨慎 | 周期长/门槛高，非首选 |

常见评分速查：

| 项目类型 | 三维 (effort, barrier, monetization) | 信心指数 |
|:---|:---:|:---:|
| 数字产品/虚拟资料 | (1, 1, 5) | 100 |
| 迁移服务类 | (2, 2, 5) | 85 |
| 模板工具 | (2, 1, 4) | 84 |
| 开源库转 API | (2, 2, 4) | 77 |
| 双边平台 | (3, 3, 3) | 54 |
| 企业级 B2B SaaS | (4, 4, 3) | 39 |
